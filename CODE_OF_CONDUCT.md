# Code of Conduct

## Our Standard

We want Phone Intel Bot to be a welcoming, practical, and technically focused open-source project.

Participants are expected to:

- Be respectful and constructive.
- Assume good intent while challenging ideas technically.
- Focus feedback on code, behavior, documentation, and evidence.
- Welcome different experience levels and backgrounds.
- Keep discussions relevant to the project.
- Protect privacy and avoid sharing sensitive personal information.

## Unacceptable Behavior

Examples include:

- Harassment, discrimination, threats, or personal attacks.
- Deliberate disclosure of private information.
- Malicious spam or disruptive behavior.
- Intentionally submitting harmful code or credentials.
- Using project discussions to facilitate unauthorized access to systems.

## Enforcement

Project maintainers may remove comments, close discussions, reject contributions, or restrict participation when necessary to keep the project safe and productive.

If you experience or observe unacceptable behavior, contact the maintainer privately through the project's GitHub contact channels.

## Scope

This Code of Conduct applies to project repositories, issues, pull requests, discussions, and other project spaces maintained by the project.
