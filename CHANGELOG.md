# Changelog

All notable changes to Phone Intel Bot are documented here.

The project follows a simple release-oriented format inspired by [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- Open-source contribution workflow and documentation.
- Security policy and responsible disclosure guidance.
- Code of Conduct.
- GitHub Issue templates for bugs and feature requests.
- Pull Request template.
- Automated CI for Python 3.12 and 3.13.
- Expanded project documentation and privacy guidance.

### Planned

- Broader automated test coverage.
- Provider health/status reporting.
- More pluggable metadata providers.
- Release automation.
- Optional container deployment.

## [2.0.0] - 2026-08-21

### Added

- Modular Telegram bot architecture.
- Public phone metadata lookup using `phonenumbers`.
- Network, DNS, web, email, QR, cryptographic, and developer utilities.
- Async SQLite persistence.
- Provider abstraction for phone metadata implementations.
- Rate limiting and caching infrastructure.
- Test suite using pytest and pytest-asyncio.
- Privacy-aware logging and usage guidance.
